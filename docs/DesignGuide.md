# BoatMeter v2 Design Guide

## 1. コンセプト

### 1.1 デザインコンセプト名
Future Lab Design

### 1.2 方向性
- 近未来感を持つマリン計器として統一する
- 「スマホの傾斜計」ではなく「計測機器」に近い体験へ寄せる
- シンプルさを保ちつつ、高級感と視認性を両立する
- 昼夜を問わず見やすい表示を優先する
- ベースカラーはネイビー、アクセントはシアンに統一する
- 写真画像ではなく SVG イラストで船体・海面・計器の表現を統一する

### 1.3 目的
- ROLL と PITCH を、単なる角度数字の表示ではなく、海上の姿勢を理解しやすい可視化として提示する
- 既存の「丸窓レイアウト」と「4ボタン構成」を維持しつつ、未来志向のデザインへ昇華させる
- 将来的なパーツ差し替えを前提にした、レイヤー分離とアニメーション可能な構成にする

---

## 2. カラー

### 2.1 基本カラー
- ネイビー：#07121F
- 深海ブルー：#10263D
- 上部光沢：#1D3A57

### 2.2 アクセントカラー
- シアン：#00D4FF
- シアン薄：#54E4FF
- 透明感のあるブルー：rgba(0, 212, 255, 0.18)

### 2.3 テキストカラー
- メイン値：#00D4FF
- 補助テキスト：rgba(255, 255, 255, 0.62)
- 重要警告：#FF4B4B

### 2.4 色使いルール
- 背景はネイビーを基調にし、中央の計器領域だけ明度差を作る
- 角度値はシアンで強調し、補助情報は白系で抑える
- 視認性を優先し、テキストと背景のコントラストは高めに設計する
- 画面全体に色を散らしすぎず、シアンのアクセントを計器の中で機能的に置く

---

## 3. フォント

### 3.1 表示フォント
- 本体フォントは OS 標準のサンセリフ系を使用
- 例: -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif

### 3.2 文字設計ルール
- タイトルは小さく、上下の余白を確保し、レイアウトの安定感を出す
- 数字は太めのウェイトで、読み取りに優れたサイズ感を確保する
- ROLL / PITCH のラベルは軽めの字幅で、視線の邪魔をしない
- 文字の視認性は「高いコントラスト + 少しのハイライト」が基本

### 3.3 フォントの使い分け
- タイトル: 12px 前後、軽め、字間を少し広げる
- 角度値: 44px〜56px、太字、アクセントカラーで強調
- 補助ラベル: 14px 前後、弱めの色

---

## 4. 余白ルール

### 4.1 基本原則
- 余白は「視線を安定させるための設計要素」として扱う
- 画面上部・下部に確保する最低限の安全余白を常に確保する
- 余白は均等にしすぎず、レイアウトの強弱を作る

### 4.2 視覚バランス
- title と value の間隔は短くし、読み取りの連続性を保つ
- 計器枠と角度値の間には最小限の余白を設け、情報密度を下げすぎない
- ボタン群は下端に固定し、計器の視界を遮りすぎない

### 4.3 端末対応
- 安全エリアを考慮し、上部・下部の余白を端末の切り欠きやホームインジケータに合わせて確保する
- 縦向き案内表示時も、UI のBasic Layout を崩さないようにする

---

## 5. SVG 構成

### 5.1 使用方針
- 画像は写真ではなく、船体・海面・計器枠・背景などを SVG で構成する
- 最終的に複数レイヤーとして独立させ、回転・上下移動・固定線を制御しやすくする
- SVG は「図形の組み合わせ」と「変形の制御」を前提に設計する

### 5.2 SVG の役割
- 船体のシルエットを簡潔に表現する
- キャビン・窓ガラス・影を独立させ、立体感を作る
- 海面の平面ラインと波形を別レイヤーに分離し、アニメーションに耐える設計を行う

### 5.3 形状設計の基本
- 船の輪郭は単純で識別しやすい形にする
- キャビン・窓は直線と曲線を組み合わせて、未来的な計器感を強める
- 海面は滑らかな線と明暗差で、動きと高さを伝える
- 波や影は後からアニメーション可能な構造にする

---

## 6. レイヤー構成

### 6.1 設計方針
すべての要素を独立レイヤーとして扱い、将来的に「波だけ上下アニメーション」「船体だけ回転」「水平線固定」を実現できるようにする。

### 6.2 推奨レイヤー
1. 船体
   - 船のシルエット本体
   - 向きや角度で回転可能

2. キャビン
   - 船の上部構造や乗員室の見える部分
   - 船体に対して相対的に配置

3. 窓ガラス
   - キャビンのガラス面や反射の表現
   - 高級感を演出するために光沢を持たせる

4. 水平線
   - 計器内の基準線
   - 固定配置で、船体の回転に対して安定した計測基準を保つ

5. 海面
   - 船体の下側に見える海面の平面
   - 波と分離して制御可能な構造にする

6. 波
   - 上下アニメーション対象
   - 速度や強さを変えられるようにする

7. 影
   - 船体や海面に立体感を与える
   - 光源方向を固定し、重なりを一貫させる

### 6.3 レイヤー間の関係
- 波は海面の上で動き、船体は独立して回転する
- 水平線は固定し、船体の姿勢だけをスムーズに見せる
- キャビン・窓・影は船体の一部として扱うが、将来的な差し替えを可能にする

---

## 7. アニメーション方針

### 7.1 基本設計
- アニメーションは「情報の見え方を補助するもの」とし、過剰な演出は避ける
- 動きは小さく滑らかにし、計測の読み取りを妨げないようにする
- 角度変化はリアルタイム感を持たせつつ、視認性を優先する

### 7.2 予定されるアニメーション
- 波だけ上下アニメーション
  - 小刻みな揺らぎで海の存在感を出す
  - 回転の妨げにならないように、上下動は小さめに設定する

- 船体だけ回転
  - ROLL / PITCH の角度に応じて船体を回転させる
  - 角度値の変化と連動するようにする

- 水平線固定
  - 計器の基準線は常に水平を保ち、船体の姿勢変化を比較しやすくする

### 7.3 アニメーション速度ルール
- 表示更新に対して過度な負荷をかけない
- 変化は 60fps を目標とし、端末性能に応じて最適化する
- UI の読み取り性が損なわれる場合は、アニメーションを軽くする

---

## 8. アイコン方針

### 8.1 アイコンの基本方針
- ボタンや状態表示は文字ベースを基本にし、アイコンは最小限にする
- 「海・船・計測」というキーワードを視覚化したシンボルを使う
- アイコンは装飾ではなく、意味を補完する用途に限定する

### 8.2 設計のルール
- アイコンは 1 色で統一し、シアンのアクセントを少し入れる
- 形は直線と丸みを組み合わせ、未来感を出す
- 小サイズ表示でも判別できる簡潔さが必要

### 8.3 用途別の考え方
- 取得 / ゼロ / 記録 / 解析 の各ボタンは文字ベースを維持し、アイコン追加は最小限にする
- 必要な場合のみ、状態表示（記録中、GPS 待機）で点やスパークのような簡易アイコンを使う

---

## 9. UI ルール

### 9.1 既存 UI 維持方針
- 現在の丸窓レイアウトを維持する
- ボタン数は増やさない
- 使いやすい構成・操作順は維持する
- ボタンの配置やクリック対象の大きさを崩さない

### 9.2 画面の見せ方
- ROLL と PITCH は平行に見えるように配置し、画面の安定感を保つ
- 値表示は視線の中心に寄せ、船体と同時に読めるようにする
- 計器枠と背景は区別し、情報の階層を明確にする

### 9.3 操作性
- スマートフォンの直感的操作を優先する
- 一度に見せる情報量は最小限にし、内部の表示は計器の焦点に集中させる
- 画面遷移やボタン操作は、現在の「すぐ使える」体験を壊さない

### 9.4 レスポンシブ対応
- 横向き使用を前提にしつつ、縦向きでは案内表示を行う
- 端末の高さが低い場合でも、値表示と丸窓の比率を崩さない

---

## 10. 今後のデザイン拡張方針

### 10.1 拡張の方向性
- 単一画面での表示を基本として、将来的な解析画面や履歴画面にも同じデザイン言語を流用する
- 船体アニメーション、海面の状態、センサー品質表示などを段階的に追加できるようにする
- 計器の色・光量・情報密度を調整し、モードごとの差別化を行う

### 10.2 将来追加可能な要素
- 波の高さ表示
- 速度・GPS 状態・センサー精度の補助表示
- 記録中の状態インジケータ
- 解析画面の共通テーマ化
- 夜間モードや高コントラストモードの段階追加

### 10.3 設計原則
- 機能追加で UI の複雑化を避ける
- すべての拡張は既存の「丸窓 + 4ボタン」の基本構造を壊さない
- 計器の見た目を変えつつ、操作に慣れたユーザーに違和感を出さない

---

## 11. まとめ

BoatMeter v2 のデザインは、「マリン計器としての未来感」をコンセプトに据え、既存の使いやすさを保ちつつ、近未来的な視認性と高級感を備えた表現へ進化させる。

要点は以下の通りである。
- ベースはネイビー、アクセントはシアン
- 船の姿勢は SVG レイヤーで可視化する
- 波・船体・水平線を独立に制御する
- 丸窓レイアウトとボタン数は維持する
- 将来の機能拡張に耐えるシンプルな設計にする
